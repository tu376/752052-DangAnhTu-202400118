The Aims class must be updated to handle any exceptions generated when the play() methods
are called. What happens when you don’t update for them to catch?

Answer: 
-When calling the play() method, if an exception occurs and it is not caught or handled in the Aims class, the exception will propagate up to the caller.

-If the exception is a checked exception (which must be handled or declared), and you don’t handle or declare it, the program won’t compile.

-If it’s an unchecked exception (runtime exception) and is not caught, the program may run but will crash at runtime when the exception occurs.
